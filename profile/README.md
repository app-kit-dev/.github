## App-Kit

Free web tools and developer APIs — fast, no sign-up, no watermarks.

**Tools** — [app-kit.dev/tools](https://app-kit.dev/tools)

- **Image compressor** — shrink JPG, PNG, WebP and AVIF without visible quality loss
- **Image converter** — WebP / AVIF / PNG / JPG in one click
- **SEO audit** — a full technical SEO and AI-readiness check of any site, with a PDF report

**API** — automate the same tools from your own code, pay per use with credits.

Built by a small independent team: [Vitaliy Sazonov](https://wm2.dev) and [Dmitry Chernenko](https://dmitry-chernenko.me).
